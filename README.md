# Social Pulse · SNS KPI 대시보드

인스타그램과 유튜브 성과를 비교하는 한국어 대시보드입니다. 별도 빌드나 패키지 설치가 필요 없는 HTML/CSS/JavaScript로 제작했습니다.

## 실행

`dist/index.html`을 브라우저에서 열거나 정적 웹 서버로 `dist` 폴더를 서비스하세요.

Python이 설치되어 있다면:

```sh
python -m http.server 4173 --directory dist
```

브라우저에서 http://localhost:4173 을 엽니다. 정적 호스팅 시 게시 폴더는 `dist`입니다.

## 기능

- 주간 조회수 목표와 달성률, 목표 수정 및 브라우저 저장
- 최근 4개 완료 주 평균에 10% 성장을 더한 추천 목표
- 인스타그램·유튜브별 팔로워/구독자, 유효 게시글, 조회수, 전환수, 댓글
- 1일·7일·30일·전체 기간 필터 및 일별 조회수 차트
- 콘텐츠별 데모 썸네일, 채널 필터, 성과 정렬
- 전체 일별 데이터, 채널 요약, 콘텐츠 성과 CSV 다운로드
- 업데이트 기록 페이지 (`#updates`)

## 데이터와 알림

모든 성과 데이터는 2026년 10월 23일 기준으로 생성한 60일 분량의 임의 데이터입니다. 실제 SNS API는 연결되어 있지 않습니다. 삭제·비공개 콘텐츠는 집계에서 제외됩니다. 전환수는 좋아요·저장·공유·리포스트의 합계입니다.

목표는 브라우저의 localStorage에 저장되며 기기 간 동기화되지 않습니다. 매주 월요일 오전 9시(한국 시간) 알림은 원래 Codex 채팅에서 별도로 설정한 자동화입니다. 이 저장소만 실행하면 알림이 발송되지는 않습니다.

`dist/thumbnails`에는 직접 제작한 데모 SVG 일러스트가 포함되어 있습니다. 실제 데이터 연결 시 각 콘텐츠의 썸네일 경로로 교체할 수 있습니다.
